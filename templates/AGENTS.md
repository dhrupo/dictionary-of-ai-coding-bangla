# <প্রজেক্টের নাম>

<এক-দুই লাইনে প্রজেক্ট কী — যেমন: ছোট্ট একটা টু-ডু ওয়েব অ্যাপ। ফ্রন্টএন্ড <React>, ব্যাকএন্ড <Node>।>

## কীভাবে চালায়

```
<install কমান্ড>   # ডিপেনডেন্সি বসানো — যেমন pnpm install
<dev কমান্ড>       # লোকাল সার্ভার চালু — যেমন pnpm dev
```

## কীভাবে টেস্ট করে

```
<test কমান্ড>      # পুরো টেস্ট স্যুট — যেমন pnpm test
```

> কোড বদলালে এটা পাস করানো বাধ্যতামূলক।

## নিয়ম-কানুন (convention)

- ইন্ডেন্ট: <২ স্পেস / ৪ স্পেস / tab>
- প্যাকেজ ম্যানেজার: <শুধু pnpm — npm/yarn নয়>
- <আরও কোনো প্রজেক্ট-নির্দিষ্ট নিয়ম থাকলে এখানে>
- বড় স্টাইল গাইড এখানে নয় — সেটা `.claude/skills/`-এ আছে

## যা করবে না

- <যা করা যাবে না — যেমন: main ব্রাঞ্চে সরাসরি push কোরো না>
- <যেমন: সিক্রেট/`.env` ফাইল কমিট কোরো না>
